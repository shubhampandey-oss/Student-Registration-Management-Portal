## What Level 1 Covers
Level 1 establishes the core server infrastructure and basic form handling:

1. **Express.js server setup** with routing and middleware
2. **EJS server-side rendering** for dynamic HTML output
3. **HTML forms** with proper labels, IDs, and accessibility attributes
4. **Server-side validation** — the essential security layer
5. **Client-side validation** (Task 2) — UX improvement layer
6. **Responsive layout** using Bootstrap 5

## Technologies Introduced
| Technology | Purpose |
|---|---|
| Node.js | JavaScript runtime |
| Express.js | HTTP server + routing |
| EJS | Server-side HTML templates |
| Bootstrap 5 | Responsive CSS framework |
| Morgan | HTTP request logging |
| dotenv | Environment variable management |
